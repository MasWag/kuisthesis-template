\begin{jabstract}
この文書は、定理環境がセクションごとに番号付けされることを確認するテストです。
\verb|\newtheorem{thm}{定理}[section]| を使用することで、定理番号が「定理 1.1」のように
セクション番号と共に表示されます。また、複数の定理型環境が同じカウンタを共有する場合
（\verb|\newtheorem{lem}[thm]{補題}|）も正しく動作することを確認します。
さらに、\verb|\ref{}| による相互参照が正しく機能することも検証します。
\end{jabstract}

\begin{eabstract}
This document tests that theorem environments can be numbered within sections.
By using \verb|\newtheorem{thm}{定理}[section]|, theorem numbers will be displayed
in the format "定理 1.1" with the section number. It also verifies that multiple
theorem-like environments can share the same counter using the syntax
\verb|\newtheorem{lem}[thm]{補題}|. Additionally, it tests cross-references
using \verb|\ref{}|.
\end{eabstract}

\section{結論}

この文書により、以下のことが確認されました：
\begin{itemize}
\item \verb|\newtheorem{thm}{定理}[section]| により、定理がセクションごとに番号付けされる
\item 番号の形式は「定理 X.Y」となる（Xはセクション番号、Yはそのセクション内の定理番号）
\item \verb|\newtheorem{lem}[thm]{補題}| により、複数の環境が同じカウンタを共有できる
\item サブセクション内でも、親セクションの番号が使用される
\item 新しいセクションに入ると、カウンタが正しくリセットされる
\item \verb|\ref{}| による相互参照が正しく機能する
\end{itemize}
