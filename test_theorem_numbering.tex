\begin{eabstract}
This document tests the theorem numbering fix in kuisthesis.sty version 3.01.
It verifies that theorems defined with the [section] option are numbered 
correctly as "定理 1.1" instead of "定理 第1章.1".
\end{eabstract}

\tableofcontents

\section{はじめに}

本節では定理番号の修正について説明する。

\subsection{背景}

以前のバージョンでは、\verb|\newtheorem{theorem}{定理}[section]| のように
定理環境を定義すると、定理番号に章番号全体（「第1章」）が含まれてしまい、
「定理 第1章.1」のように表示されていた。

\subsection{解決方法}

バージョン 3.01 では、\verb|\thesection| の定義を変更し、内部的には単に
アラビア数字を返すようにした。一方、章見出しの表示には \verb|\@seccntformat|
を使用して「第N章」を表示する。

\section{定理の例}

本節では実際に定理を定義して、番号が正しく表示されることを確認する。

\begin{theorem}
この定理は「定理 2.1」と番号付けられるべきである。
「定理 第2章.1」とはならない。
\end{theorem}

\begin{proof}
証明は省略する。
\end{proof}

\begin{lemma}
この補題は「補題 2.2」と番号付けられるべきである。
\end{lemma}

\begin{definition}
この定義は「定義 2.1」と番号付けられるべきである。
\end{definition}

\begin{theorem}
この定理は「定理 2.3」と番号付けられるべきである。
\end{theorem}

\section{検証}

本節でさらに定理を定義する。

\begin{theorem}
この定理は「定理 3.1」と番号付けられるべきである。
前の章からの連番ではなく、章ごとに番号がリセットされる。
\end{theorem}

\subsection{副節での定理}

副節でも定理を定義できる。

\begin{theorem}
この定理は「定理 3.2」と番号付けられるべきである。
副節に含まれていても、章単位で番号付けされる。
\end{theorem}

\section{おわりに}

本文書により、定理番号が正しく動作することを確認した。
